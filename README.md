### Hi, I'm Tiago 👋

I'm a **physics engineer moving into data science** — I like taking messy, physical, real-world signals and turning them into something you can actually reason about. Most of what I build ends up open source, because I learn best in public.

Lately that means a lot of **Home Assistant** work: reverse-engineering BLE devices, writing integrations, and building custom firmware for hardware that shipped without a decent API.

**I'm currently looking for my next role in data science / data engineering.** If you're hiring, or just want to talk shop, my inbox is open.
